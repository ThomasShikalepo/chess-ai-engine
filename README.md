# Chess AI Engine

## Overview
This repository contains a Python-based chess game built using Pygame, featuring a Minimax-powered AI opponent and sound effects for an immersive experience. Players can enjoy a classic chess match against an intelligent computer opponent. The game leverages the Minimax algorithm with alpha-beta pruning to provide a challenging AI that makes strategic moves.

## Features
- **Pygame-based Interface**: A graphical chessboard for an interactive user experience.
- **Minimax AI**: An intelligent computer opponent powered by the Minimax algorithm with alpha-beta pruning for efficient decision-making.
- **Sound Effects**: Audio cues for moves, captures, and game events to enhance gameplay.
- **Standard Chess Rules**: Supports all standard chess rules, including castling, en passant, and pawn promotion.
- **Customizable Settings**: Options to adjust AI difficulty or game parameters (if implemented).
